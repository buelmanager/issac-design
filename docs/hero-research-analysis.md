## 리서치 파트

### 0. 히어로 섹션의 중요성과 가치

#### 핵심 지표

| 핵심 지표 | 수치 | 출처 |
|---|---|---|
| 사용자 Above-the-fold 체류 시간 | 전체 조회 시간의 **57%** | Omniconvert |
| 첫인상 형성 시간 | **0.05초** (50ms) | Socialectric |
| 제안 이해 실패 시 이탈률 | 3초 내 이해 못하면 **37% 이탈** | ofspace |
| Above-fold CTA vs Below-fold | **304%** 더 높은 성과 | nudgenow |
| 명확한 CTA의 전환율 증가 | **161%** 향상 | WiserNotify |
| 미디어 100KB당 이탈률 증가 | **+1.8%** | PerfectAfternoon |
| 3초 이상 로딩 시 모바일 이탈 | **53% 이탈** | Google |
| 히어로 섹션 모바일 문제 비율 | **25%** | ofspace (100개 스타트업 조사) |

#### 핵심 인사이트

- **히어로는 디지털 매장의 쇼윈도우** — 브랜드 정체성, 가치 제안, 첫인상을 동시에 전달하는 가장 중요한 영역
- **잘 설계된 히어로**는 스크롤 깊이 증가, 이탈률 감소, 전환율 극적 향상으로 이어짐
- **핵심 질문**: "사용자를 위한 것이 무엇인가?"에 즉각 답하는 **단일 가치 제안**이 있어야 함
- 사용자의 57%의 시간이 Above-the-fold에 집중되므로, 히어로 영역의 모든 요소는 전환에 기여해야 함

### 1. 히어로 섹션이 지녀야 하는 기능과 역할

#### 필수 요소 (Must-Have)

| # | 요소 | 설명 | 근거 |
|---|---|---|---|
| 1 | **명확한 헤드라인** | "What's in it for me?"에 답하는 가치 제안 | 3초 내 이해 못하면 37% 이탈 |
| 2 | **보조 서브헤드라인** | 맥락과 세부 정보 제공 | 헤드라인만으로 부족한 정보 보완 |
| 3 | **하나의 주요 CTA + 선택적 보조 CTA** | 행동 유도 버튼, 고대비 디자인 | Above-fold CTA가 304% 높은 성과 |
| 4 | **고품질 비주얼** | 메시지를 지원하는 이미지/영상 | 첫인상 0.05초 내 형성 |
| 5 | **사회적 증거** | 리뷰, 통계, 배지 등 신뢰 지표 | Above-the-fold에 항상 노출 필수 |
| 6 | **반응형 모바일 디자인** | 모바일 50~70vh 최적화 | 히어로 모바일 문제 비율 25% |
| 7 | **빠른 로딩** | 3초 이내 완전 로딩 | 3초 초과 시 53% 모바일 이탈 |
| 8 | **시각적 계층 구조** | 시선 흐름 유도 (아이브로 → 헤드라인 → CTA) | 인지 부하 감소, 즉각적 이해 |
| 9 | **충분한 여백** | 요소 간 호흡, 클린한 레이아웃 | 정보 과부하 방지 |

#### 선택적 강화 요소

- **카테고리 퀵 네비게이션** — 히어로에서 바로 제품 카테고리 접근
- **카운터 애니메이션** — 경력, 실적 수치를 동적으로 표현
- **배경 영상/이미지 Ken Burns 효과** — 정적 이미지에 동적 느낌 부여
- **개인화** — 유입 경로별 맞춤 메시지 (광고, 검색, 직접 방문 등)

## 분석 파트 — 현재 ShopHero 진단

### 현재 구현 요약

- **파일**: `src/components/shop/ShopHero.astro` (985줄)
- **구조**: 4슬라이드 캐러셀 + 4개 배경 영상 + GSAP 애니메이션
- **영상 용량**: hero1.mp4(8.8MB) + hero2.mp4(4.6MB) + hero3.mp4(8.8MB) + hero4.mp4(4.6MB) = **총 26.8MB**
- **CTA**: 단일 고스트 버튼 ("제품 둘러보기")
- **신뢰 지표**: 슬라이드 2에서만 5초간 노출 ("15년, 1,000건")

### 현재 상태 vs 리서치 기준 비교

| 항목 | 리서치 기준 | 현재 ShopHero | 상태 |
|---|---|---|---|
| 가치 제안 명확성 | 3초 내 이해 | "디자인입니다" → 추상적, 고객 혜택 미표현 | ❌ 미달 |
| CTA 배치 | Above-fold, 고대비, 복수 CTA | 단일 고스트 버튼 (투명 배경, 저대비) | ⚠️ 약함 |
| 신뢰 지표 노출 | 항상 보이게 (Above-the-fold) | 슬라이드 2에만 존재 (5초 노출) | ❌ 미달 |
| 미디어 용량 | 최소화 (100KB당 이탈률 +1.8%) | **26.8MB** (4개 MP4 영상) | ❌ 과다 |
| 모바일 경험 | 동적 + 최적화 | 영상 숨김, 정적 포스터 이미지만 표시 | ⚠️ 부족 |
| 텍스트 전달 속도 | 1초 내 가독 | 글자별 애니메이션 ~2초 소요 | ⚠️ 느림 |
| 코드 복잡도 | 모듈화 | 985줄 모놀리식 (HTML+CSS+JS 단일 파일) | ⚠️ 개선 필요 |

### 상세 문제점 9가지

#### 1. 가치 제안 실패

**현재**: "간판은 디자인입니다" (슬라이드 0 헤드라인)

```
문제: 시적이고 추상적 → "이 회사가 나에게 뭘 해주나?"에 답하지 못함
```

- 방문자가 3초 내에 이해하지 못하면 37% 이탈
- B2B 고객(가게 사장님)은 "내 가게 간판을 어떻게 만들어줄까?"가 궁금함
- "디자인입니다"는 브랜드 메시지이지, 고객 혜택이 아님

#### 2. CTA 약함

**현재**: 단일 고스트 버튼 "제품 둘러보기" (lines 135-142)

```html
<a href="#products" class="shop-hero__cta-btn">
  <!-- 투명 배경, 얇은 흰색 보더 — 저대비 -->
</a>
```

- 고스트 버튼은 배경 영상 위에서 시인성 떨어짐
- "견적 문의" CTA 부재 — B2B 핵심 전환 액션 누락
- 리서치: 명확한 CTA가 전환율 161% 향상, 듀얼 CTA가 효과적

#### 3. 신뢰 지표 매몰

**현재**: "15년, 1,000건 신뢰가 만든 품질" — 슬라이드 2 헤드라인으로만 존재

```
문제: 4슬라이드 캐러셀에서 슬라이드 2는 자동 전환(5초)으로만 약 5초간 노출
      → 75% 이상의 방문자가 신뢰 지표를 보지 못할 가능성
      → 리서치: 사회적 증거는 Above-the-fold에 "항상" 노출되어야 함
```

#### 4. 영상 과부하

**현재**: 4개 MP4, 총 26.8MB

| 파일 | 용량 |
|---|---|
| hero1.mp4 | 8.8MB |
| hero2.mp4 | 4.6MB |
| hero3.mp4 | 8.8MB |
| hero4.mp4 | 4.6MB |
| **합계** | **26.8MB** |

- 리서치: 미디어 100KB당 이탈률 +1.8% → 26.8MB = **이탈률 +482% 위험**
- 3초 이상 로딩 시 모바일 53% 이탈
- 4G 환경(평균 20Mbps)에서 26.8MB 로딩 시간 ≈ **10.7초**

#### 5. 애니메이션 지연

**현재**: 글자별 분할 애니메이션 (lines 655-692)

```javascript
// 초기 지연: 0.5초
delay: isInitial ? 0.5 : 0.15

// 글자 스태거: amount 0.6 (전체 0.6초에 걸쳐 분산)
stagger: { amount: 0.6, from: 'start' }

// 글자 개별 duration: 0.5초
duration: 0.5
```

- 결과: 첫 슬라이드 메시지 완전 표시까지 약 **2초 소요**
- 리서치: 사용자는 0.05초에 첫인상 형성 → 2초는 과도한 지연
- 눈길 끄는 효과 vs 메시지 전달 속도 트레이드오프에서 "속도"가 우선

#### 6. 캐러셀 효과 의문

**현재**: 4슬라이드 자동 캐러셀 (5초 간격)

```
문제:
- 어느 시점에서든 75% 콘텐츠가 숨겨져 있음
- 슬라이드 3의 메시지는 15초 후에나 노출
- 리서치: 캐러셀은 단일 포커스 메시지보다 전환 성과 낮음
- 각 슬라이드가 독립적 메시지 → 통합된 가치 제안 부재
```

#### 7. 영어 아이브로 텍스트

**현재 아이브로**:
- "DESIGN EXCELLENCE" (슬라이드 0)
- "FULL LINEUP" (슬라이드 1)
- "SINCE 2010" (슬라이드 2)
- "ONE-STOP SERVICE" (슬라이드 3)

```
문제: 한국 B2B 고객(가게 사장님) 타겟에 부적합
- 영어 아이브로는 "고급스러움"을 의도하지만, 타겟 고객에게 의미 전달 실패
- "DESIGN EXCELLENCE"가 간판과 무슨 관련인지 즉시 파악 어려움
```

#### 8. 카테고리 진입점 부재

**현재**: 히어로 → #products 단일 CTA만 존재

```
문제:
- LED 채널간판, 네온사인, 현수막 등 구체적 니즈를 가진 방문자가
  히어로에서 바로 원하는 카테고리로 진입할 수 없음
- FASTSIGNS 레퍼런스: 3개 차별화 CTA로 다양한 니즈 동시 대응
```

#### 9. 모바일 동적 요소 부재

**현재 모바일 처리** (lines 524-530):

```css
@media (max-width: 719px) {
  .shop-hero__video { display: none; }
  .shop-hero__poster { display: block; }
}
```

- 영상을 완전히 숨기고 정적 포스터 이미지만 표시
- 모바일 사용자 비율이 50~70%인 상황에서 동적 경험 부재
- Ken Burns 효과 등으로 정적 이미지에 동적 느낌 부여 가능
